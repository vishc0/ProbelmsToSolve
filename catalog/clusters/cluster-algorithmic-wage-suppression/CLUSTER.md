# Problem Cluster: Algorithmic Wage Suppression

> Opaque automated systems set individualized pay and work access without meaningful accountability.

## Shared root cause

Platforms and employers possess granular worker data and unilateral control over scoring, task allocation, pay offers, and deactivation, while workers cannot inspect or effectively contest those decisions.

## Examples

- Gig-platform pay and deactivation.
- Warehouse productivity scoring.
