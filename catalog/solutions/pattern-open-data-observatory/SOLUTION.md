# Solution Pattern: Open Data Observatory

> Publish a reproducible data pipeline, static views, and neutral explanations of consequential systems.

## Applicable context

Use when public datasets can make governance, logistics, or infrastructure outcomes easier to inspect without advocating a predetermined policy.

## Pattern

Record dataset versions and licences, transform data reproducibly, publish methods and limitations, and separate observed facts from interpretation.

## Tradeoffs and failure modes

Source coverage, definitions, and licensing can distort comparisons. A polished chart can overstate incomplete or stale evidence.

## Safety and cost boundaries

Use open or appropriately licensed data, keep analysis neutral, disclose uncertainty, and generate static outputs at zero spend.
