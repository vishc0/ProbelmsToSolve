# Domain: Global Cooperation and Peace

> Transparent, accountable institutions and practical mechanisms for peaceful international cooperation.

- Domain ID: `global-cooperation-and-peace`
- Status: proposed; owner decision required

## Scope

International institutional representation, vetoes, commitments, dispute resolution, and neutral tools that make cooperation outcomes inspectable.

## Boundaries

This domain supports evidence and analysis, not partisan advocacy or automated decisions about diplomacy, conflict, or sanctions.
