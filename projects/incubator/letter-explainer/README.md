## What It Does
When you get a letter filled with confusing language, this tool breaks it down into three simple things:
1. **What it actually means:** A short summary in plain English.
2. **Key dates and money:** Any deadlines or amounts you need to pay.
3. **A draft reply:** A polite, professional response you can copy, edit, and send back.

## How to Run It
```bash
python3 src/letter_explainer.py --file sample_letter.txt
```
