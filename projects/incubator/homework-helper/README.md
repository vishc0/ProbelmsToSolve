## What It Does
When your child asks for help with schoolwork you haven't seen in 20 years:
1. **Parent Refresher:** Explains the underlying rule in 2 plain sentences so you understand it immediately.
2. **Watch-Out:** Highlights the common mistake kids make on this specific type of problem.
3. **Guiding Hint:** Gives you a question or hint to say out loud to guide your child to the answer themselves, without just doing the homework for them.

## Supported Topics
- Fractions (adding, subtracting, multiplying)
- Negative numbers (adding, subtracting, double negatives)
- Basic Algebra (solving for $x$)
- Percentages & Discounts
- Order of Operations (PEMDAS)

## How to Run It
```bash
python3 src/homework_helper.py --topic "negative numbers" --problem "-5 - (-8)"
```

Run tests:
```bash
python3 tests/test_homework_helper.py
```
