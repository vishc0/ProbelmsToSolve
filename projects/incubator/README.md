# Incubator Projects

This directory contains practical, working tools addressing real-world problems.

---

## Practical Everyday Tools (Ready to Use)

| Project | What It Does | Run Command |
| :--- | :--- | :--- |
| **[`letter-explainer/`](letter-explainer/)** | Turns confusing legal/landlord/insurance letters into a plain English summary, lists deadlines/amounts, and drafts a polite reply. | `python3 letter-explainer/src/letter_explainer.py` |
| **[`lab-result-explainer/`](lab-result-explainer/)** | Explains routine blood test results in calm, normal words and lists 3 questions to ask your doctor. | `python3 lab-result-explainer/src/lab_explainer.py` |
| **[`subscription-checker/`](subscription-checker/)** | Reads bank/credit card CSV statements, detects recurring monthly subscriptions, and flags sneaky price hikes. | `python3 subscription-checker/src/subscription_checker.py` |
| **[`homework-helper/`](homework-helper/)** | Provides parents with a 2-sentence math refresher and guided step-by-step hints to help kids without giving the answer away. | `python3 homework-helper/src/homework_helper.py` |
| **[`scam-checker/`](scam-checker/)** | Evaluates suspicious text messages or emails (fake package deliveries, gift card demands) and clearly explains the red flags. | `python3 scam-checker/src/scam_checker.py` |
| **[`quick-invoice/`](quick-invoice/)** | Converts rough spoken or typed job notes into a clean, professional invoice for tradespeople and solo contractors. | `python3 quick-invoice/src/quick_invoice.py` |
