## What It Does
When blood tests are posted online over the weekend, it's easy to panic over numbers you don't understand. This tool:
1. Explains what the test actually measures in everyday language.
2. Checks whether the number is in the standard reference range.
3. Provides 3 clear, practical questions to ask your doctor at your next visit.

*Note: This tool is strictly for patient education and understanding. It does not provide medical diagnoses.*

## How to Run It
```bash
python3 src/lab_explainer.py
```

Or pass specific values:
```bash
python3 src/lab_explainer.py --test "Fasting Glucose" --value 108
```

Run tests:
```bash
python3 tests/test_lab_explainer.py
```
