# Bill Auditor

A local-first tool that explains household bills, checks visible charges, and drafts user-reviewed questions or disputes.

## Start here

1. Read [`PROJECT.md`](PROJECT.md) for the approved outcome and scope.
2. Follow [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for component boundaries.
3. Run the checks documented in [`tests/README.md`](tests/README.md).
4. Review infrastructure cost and approval gates in
   [`infra/README.md`](infra/README.md).
5. Use [`docs/ADOPTION.md`](docs/ADOPTION.md) when another team adopts the
   project.

## Website connection

`project.json` is the website discovery manifest. `PROJECT.md` is the canonical
project specification. Set `visibility` to `public` only after publication is
approved; the website build will then include this project.
