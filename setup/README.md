# Setup

This directory owns the reproducible setup for the free-first hybrid compute
environment used by the CloudSetup MVP.

## Start here

1. Read [`resources/RESOURCE_CATALOG.md`](resources/RESOURCE_CATALOG.md) for the
   verified provider inventory.
2. Read [`architecture/HYBRID_TOPOLOGY.md`](architecture/HYBRID_TOPOLOGY.md) for
   how the laptop, hosted control plane, and workers cooperate.
3. Read [`MVP_FREE_RESOURCE_PLAN.md`](MVP_FREE_RESOURCE_PLAN.md) for the staged
   deployment sequence and approval points.
4. Use the provider runbooks only when activating that provider.
5. Read [`funding/GRANT_READINESS.md`](funding/GRANT_READINESS.md) before applying
   for credits or grants.

No setup step may create billable resources, add a payment method, expose a
service publicly, or broaden access without explicit owner approval.
