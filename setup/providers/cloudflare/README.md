# Cloudflare Setup Track

Cloudflare Pages is a candidate for the static catalog; Workers/D1 can support a
small metadata API; Workers AI can provide bounded inference. Heavy parsing and
generation remain worker jobs outside the request path.

Do not create a Tunnel or expose a laptop service until authentication, access
policy, origin hardening, and revocation have been reviewed.

Official pricing: https://developers.cloudflare.com/workers/platform/pricing/
