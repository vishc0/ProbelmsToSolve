# Google Setup Track

Use Google for scale-to-zero CPU hosting, storage, Gemini API experiments, and
interactive Colab research. The canonical current quotas and links live in
[`../../resources/RESOURCE_CATALOG.md`](../../resources/RESOURCE_CATALOG.md).

Activation checklist:

1. Confirm account eligibility and whether the free trial was previously used.
2. Define project IDs, region, labels, owner, expiration, and zero-dollar intent.
3. Configure budgets, quota limits, and log retention before deployment.
4. Start with local emulation; deploy only the smallest Cloud Run service.
5. Do not upgrade billing or attach GPUs without explicit approval.
